# Kynectia - Android Mobile App

Este directorio contendrá el subsistema de la aplicación móvil de Kynectia para dispositivos Android (smartphones y tablets).

## Responsabilidades
- Experiencia de atleta / usuario final en dispositivos móviles.
- Visualización y ejecución de rutinas de entrenamiento (`workouts`).
- Catálogo de ejercicios, anatomía muscular y equipamiento.
- Gestión de perfil de usuario, planes de suscripción y reproducción de multimedia/videos de ejercicios.
- Consumo del API REST (`backend/`).
