# Kynectia - Android TV App

Este directorio contendrá el subsistema de la aplicación de Kynectia diseñada específicamente para televisores y dispositivos Android TV / Google TV.

## Responsabilidades
- Interfaz 10-foot UI adaptada para navegación con control remoto (D-pad).
- Modo sala / gimnasio: visualización de rutinas en pantalla grande, temporizadores de series y reproducción de videos demostrativos de ejercicios.
- Integración de anuncios publicitarios (`ads`) de pantalla completa o banners de intermedio.
- Consumo del API REST (`backend/`).
